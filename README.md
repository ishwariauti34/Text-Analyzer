# Text Analyzer 📝

A simple web-based Text Analyzer built using Python and Flask.

## Features
- Enter and save text
- Count total words
- Count total characters
- Count total lines
- Find the longest word
- Save text using file handling

## Technologies Used
- Python
- Flask
- HTML
- CSS

## How to Run

1. Clone this repository.
2. Install dependencies:

   pip install -r requirements.txt

3. Run the application:

   python main.py

4. Open your browser:

   http://127.0.0.1:5000
